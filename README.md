# Revenue Administration Database

## Description

This project implements a PostgreSQL database for a Revenue Administration System.

The database manages:

- Taxpayers
- Tax Centres
- Tax Officers
- Tax Types
- Tax Registrations
- Tax Declarations
- Tax Assessments
- Tax Payments
- Audits
- Penalties
- Refunds
- Businesses
- Properties
- Vehicles

## Technologies

- PostgreSQL
- SQL
- pgAdmin / SQL Shell

## Features

- 20 relational tables
- Primary Keys
- Foreign Keys
- CHECK Constraints
- UNIQUE Constraints
- DEFAULT Values
- 100 records per table
- 20 complex SQL reports
- Entity Relationship Diagram
